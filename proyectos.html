PROXMOX & VIRTUALIZACIÓN

Proyecto integral basado en la instalación, configuración y despliegue de un entorno completo de virtualización de servidores con Proxmox VE, completamente accesible desde cualquier lugar vía Internet con infraestructura de comunicaciones seguras.

tfc-stack-architecture.log
  • Virtualizador Base: Proxmox VE con Alta Disponibilidad (HA).
  • Sistemas Operativos Desplegados: Debian, Ubuntu Server y Windows Server.
  • Redes y Seguridad: Configuración de VPNs para acceso remoto seguro.
  • Contenedores: Manejo y orquestación de servicios en Docker.
  • Bases de Datos: Creación, gestión y optimización de bases de datos MariaDB.
  • Servicios Configurados: SSH, NFS, SMB, Nginx (Reverse Proxy), LDAP, RDP, xRDP, HTTP/HTTPS entre otros.
Proxmox Docker Debian / Ubuntu / Windows Server VPNs Nginx MariaDB LDAP NFS / SMB

INFRAESTRUCTURA DE COMUNICACIONES CLR

[ PROYECTO EN EQUIPO DE ALTA DISPONIBILIDAD ]

REDES MULTI-WAN & CLOUD

Desarrollo en grupo de una infraestructura de red de alta resiliencia diseñada para comunicar un nodo Edge a la nube a través de múltiples enlaces redundantes con conmutación por error.

  • Conectividad Multi-WAN: Implementación de 3 salidas independientes a Internet (Ethernet, WiFi y 4G/5G).
  • Servidores VPN Redundantes: Despliegue de túneles VPN seguros mediante Strongswan y FortiGate.
  • Métricas en la Nube: Almacenamiento y procesamiento continuo de métricas de rendimiento de red en un servidor Cloud dedicado.
